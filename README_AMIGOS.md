# Conexión de amigos

Instala Minecraft Java 26.2 y entra mediante `<PLAYIT_PUBLIC_ADDRESS>`; el administrador debe proporcionarte el hostname y puerto reales del túnel existente. No uses la dirección del panel.

Envía al administrador tu nombre exacto de Minecraft para que lo añada a la whitelist. No se conceden privilegios OP automáticamente. Necesitas una cuenta válida porque online-mode permanece activado.

El modo es Hardcore cooperativo: una muerte termina la run de todo el grupo. Durante el reset espera el aviso y vuelve a conectar cuando el servidor esté ONLINE. Los inventarios, XP, estadísticas, avances y las tres dimensiones se reinician; los datos personales del servidor no forman parte de este repositorio.

Los mods del cliente y los shaders son opcionales. Consulta `client/README_CLIENTE.md`. No se redistribuyen sus binarios.
